# 本地任务卡模板

> 用于 GitHub 不可用（或任务未同步到 issue）时承载「任务基本信息」。
> 字段语义见 `references/public-task-contract.md` §1 与 §11（本地轨道）。
> 落盘位置：`docs/tasks/<任务标识>-<slug>.md`（入库，随任务合并进 main 长期可查）。
> GitHub 恢复后，本文件正文即补建 issue 的正文（另加 AI 生成免责声明前缀）。

## 任务基本信息

| 字段 | 值 |
|---|---|
| 任务标识 | `LOC-001` |
| 需求来源 | github-issue / 本地文档 / 会话录入 |
| 来源定位 | issue 号 / 文档路径 / 会话日期与摘要 |
| 任务名称 | |
| 任务类型 | 完整功能开发 |
| 优先级 | P0 / P1 / P2 |
| 当前状态 | 定义中 / 待确认 / 本地已定义 / 交付中 / 等待验收 / 执行受阻 / 已合并 |
| 需求基线版本 | V1 |
| 前置依赖 | 无 |
| 施工环境组 | （独立任务填本任务标识；子任务填父任务标识） |
| 施工环境角色 | 独立 / 成员 |
| 无人值守许可 | 允许 / 不允许 |
| 任务规格位置 | `.scratch/LOC-001-<slug>/task-spec-V1.md` |
| 定义时间 | （确认「本地已定义」时写入 ISO 8601） |
| GitHub 同步 | 不适用 / 待补 issue / 已同步 #N |
