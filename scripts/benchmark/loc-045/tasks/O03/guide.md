# 操作指南

## 六步流程

1. 检查工作区：确认当前分支与任务范围。
2. 安装依赖：在仓库根目录执行 npm install。
3. 生成：运行 npm run generate 更新生成物。
4. 校验：运行 npm run validate 确认一致性。
5. 呈递验收：生成 UAT 卡并进入等待验收。
6. 按授权同步：仅在获授权后推送或合并。

## 三条约束

- 不得提交凭据、本地 DSH 状态或自动生成目录内容。
- 不得直接修改 `.generated/` 目录；应改蓝图后重新生成。
- 人工未通过验收前不得发布或合并到 main。

## 外围说明（可精简）

本指南用于 LOC-045 O03 优化样板。优化目标是在保留上述六步与三条约束原句的前提下，将全文 Unicode 长度减少至少百分之二十。请勿删除步骤编号或约束条目。
