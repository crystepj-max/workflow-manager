# UAT 验收卡模板（M2）

> 自动施工阶段结束后、进入「等待验收」前必须生成。每个主要功能切片至少一个 UAT 点。
>
> **验收项必须声明「执行时机」**（本模板硬要求）：
> - **裁决前可观测** —— 人工裁决的依据；
> - **收口后观测** —— 只有在收口/合并之后才可能产生结果，集中在文末「收口后复核」区，**不是**裁决前置。
>
> **人工裁决的依据只取「裁决前可观测」项。** 若某条验收项依赖裁决之后才存在的状态（例如「主检出已包含本修复」「本任务工作区已删除」「主检出自跑全绿」），必须标为「收口后观测」，否则交付操作者照单执行必然得到假红灯。
>
> 一张卡必须至少有一项「裁决前可观测」项作为裁决依据；若全部验收项都无法在裁决前观测，属需求定义不完整，**不得**进入等待验收（退回定义阶段）。
