## 16. UAT 场景

> **每条 UAT 项必须声明「执行时机」**：**裁决前可观测**（人工裁决的依据）或 **收口后观测**（只有在收口/合并之后才可能产生结果，须写明执行者与结果回填位置）。
> 裁决依据**只取**「裁决前可观测」项；依赖裁决之后才存在的状态（如「主检出已包含本修复」「工作区已删除」「主检出自跑全绿」）必须标为「收口后观测」，否则交付操作者照单执行必然得到假红灯。
> 一张规格必须至少有一项「裁决前可观测」项作为裁决依据；若全部验收项都无法在裁决前观测，属需求定义不完整，不得进入「待确认」。
