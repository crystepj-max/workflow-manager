## 摘要（三要素）

**目标：**交付可复跑的12任务实验、逐次原始结果和有证据的采用/不采用建议；零收益或失败也形成有效研究结论。

**范围：**12个固定小任务、36次基准运行、两个有限候选在适用子集的最多12次对照、指标/质量核对与研究报告。仅隔离实验配置和夹具。 不发布简化模板，不删除独立审核/测试/人工关口，不扩大返工额度，不建立在线实验平台，不顺带实现 LOC-038/036 的生产功能，不部署第五套正式工作流。

**验收标准：**

- [ ] AC-01：提供 12 个任务的固定输入、验收判据与 3 次重复原始记录；未执行真实模型时只能交实验准备，不能宣称收益成立。
- [ ] AC-02：每个候选对照使用相同模型设置与任务，比较验收质量、证据完整度、调用、中位自动耗时、人工介入和已知费用。
- [ ] AC-03：建议逐项说明适用任务、未覆盖场景及是否满足门槛；失败实验和没有收益的结果同样保留。
- [ ] AC-04：报告没有将降低关口或降低质量当作收益，生产模板未被实验配置覆盖。
