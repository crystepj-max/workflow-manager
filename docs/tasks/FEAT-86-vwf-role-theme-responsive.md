## 摘要（三要素速览）

### 任务目标

解决两个直接的使用问题：**用户分不清内置角色和自定义角色**；**职责很长的角色把列表撑爆**。同时把编辑器、运行详情和角色管理收敛到同一套浅色 / 深色语义色、排版、焦点与窄屏规则，消除「深色背景配深色字」和按钮被遮挡。

### 涉及范围

- 做：
  - 角色列表明确「内置 / 自定义」来源：分区或筛选结果在标题与行内**均可识别**
  - 内置角色只读，可查看完整内容或复制为自定义；自定义角色可编辑 / 复制 / 删除并显示引用阻塞
  - 角色摘要独立于完整职责：优先用显式 summary；无 summary 时从职责生成**两行**可读摘要；连续长串断词或换行
  - 完整职责放在详情对话框 / 侧栏的**独立滚动区**，列表高度不随全文增长
  - 统一编辑器、运行页、角色页的浅色 / 深色语义 token（画布、表面、正文、次要正文、强调、状态、边框、焦点、遮罩成对定义）
  - 对比度：正文 ≥ 4.5:1，非文本控件 ≥ 3:1；状态同时用文字与图标 / 形状，不只依赖颜色
  - 适配 390×844 及常见桌面宽度；弹层有安全边距，按钮能折行，详情内部滚动
  - 键盘：Tab / Shift+Tab、可见焦点、Escape 关闭、打开详情后的焦点回收、真实 label
- 不做：
  - 不修改角色存储、角色内容、角色引用关系、删除规则和宿主 RPC 语义
  - 不新增角色权限层，不把内置角色改成可直接编辑
  - 不改 FEAT-84 / FEAT-85 的业务路由、运行状态、模型 override 或模板数据
  - 不以降低正文字号、隐藏文字或降低对比度解决窄屏拥挤
  - 不重新引入初版 B/C 视觉方向；沿用 A 编排台的雾蓝语义系统

### 验收标准

- [ ] V-1 角色列表一眼能区分内置与自定义；内置只读可复制，自定义可编辑 / 删除并显示引用阻塞
- [ ] V-2 长职责不撑爆列表；列表摘要最多两行，完整文本在独立滚动详情中可读，连续长串不造成横向溢出
- [ ] V-3 编辑器、运行页、角色页使用同一套 A 语义 token；浅色与深色均无低对比度文字
- [ ] V-4 普通文字对比度 ≥ 4.5:1，非文本控件 ≥ 3:1；状态同时有文字与图形提示
- [ ] V-5 390×844 下设置入口、角色列表、详情弹层与编辑表单均可操作，无横向滚动；主要操作不被工具条遮挡
- [ ] V-6 键盘可到达筛选、查看、编辑、复制、删除、关闭与保存；焦点可见；Escape 关闭详情并回收焦点
- [ ] V-7 角色 RPC 与内置 / 自定义业务语义未被视觉改造误改
- [ ] V-8 真实浏览器截图、对比度测量、自动测试与人工验收状态分别记录
