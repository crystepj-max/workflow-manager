## 摘要（三要素）

**目标：**所有建设入口对同一事实给出一致的可开工结果与原因，机械不合格时开发调用为零，合法常规任务无需模型重复裁决。

**范围：**资格校验公共入口、同组及跨组完成依赖检查、三入口适配、机械节点输出和独立服务探测诊断。 不开发新的批量依赖调度器，不自动将未定义任务标已定义，不删除模型连通性探测，不让资格检查创建工作区。

**验收标准：**

- [ ] AC-01：同一输入从 Bootstrap、正式 wf_run 和测试适配入口获得相同可开工结论及原因码。
- [ ] AC-02：已完成依赖的合法同组成员、合法本地已定义任务通过；未完成依赖、版本冲突、缺许可均受阻且 dev 未调用。
- [ ] AC-03：模型输出 PASS 不能覆盖机械失败，机械通过的常规场景不再额外消耗一次模型资格判断调用。
- [ ] AC-04：不覆盖既有模型连接探测；任务资格检查与服务就绪检查可分别定位失败。
