## 摘要（三要素）

**目标：**在一个明确支持的参考宿主配置中实际阻止越权读写/发布，并允许合法测试和证据输出；其他配置明确显示隔离能力不足。

**范围：**四模板 node_capabilities、宿主能力探测、节点隔离执行适配、只读候选/独立写区、受控发布能力及真实越权探针。 不承诺全部第三方 CLI/Profile，不修改 deepseek-harness 上游源码，不建设 RBAC 平台，不把 chmod、提示词或模型自律作为强制隔离证据。

**验收标准：**

- [ ] AC-01：review 写候选、test 写业务源码、researcher 写源树均被实际文件/工具层拒绝，而不只是模型遵守。
- [ ] AC-02：review/test 能在证据区写报告，test 能运行所需测试与缓存；合法行为不因只读候选全部失效。
- [ ] AC-03：无发布授权节点无法调用发布动作，已授权适配动作仍按原流程执行。
- [ ] AC-04：路径穿越、符号链接和直接 shell 绕过尝试均按支持的宿主边界验证；不支持强制隔离的环境明确标注能力缺失。
