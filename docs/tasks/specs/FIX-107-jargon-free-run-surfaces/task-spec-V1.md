# 运行列表/详情页技术名词全面用户化

## 1. 缺陷描述

运行列表页与运行详情页的交互文案残留实现层技术名词（Logical Run、分段、快照修订、Provider/Model、Formal Artifacts、closeout、wf_run、runId、生命周期等）。用户应当只关注如何使用产品，不需要先学习实现概念。排查清单已经松哥逐项确认（2026-09-19），本规格即确认后的最终口径。

## 3. 约束

1. **只改展示文案**：状态机取值、RPC 字段、数据契约不变；raw 值到中文的映射在展示层完成。
2. zh / en 双语同步更新（英文按同一语义重写，不再直译实现词）。
3. 断言旧文案的既有测试同步修订（如 runRowWith/按文案定位的用例）；能力级断言不删。
4. 零回退：FEAT-84/85/86/100/101/102/103 的全部行为与验收证据保持。
5. 载荷预算不上调（文案变更体量中性，仍须 build + check:dist 通过）。
6. token 集成口径（DT-02）断言保持。
