## 1. 必须决定什么

`docs/design/outcome-presets.json` 这份"结果路由预设"要给用户到什么程度：只是**修对数据**（配置仍手填）、还是做成**可点选的产品能力**（选预设即带出字段路径 + 枚举值 + 中文标签）、还是进一步允许**用户自建预设**。

## 2. 前置事实：现在这份 preset 是错的（不含产品取舍，建议先修）

| preset | 文件声明的 `outcomePath` | 正式模板实际 |
|---|---|---|
| `optimize-evaluator` | `$.verdict` | `$.route`（`templates/wf-optimize.json:36,119,156`） |
| `explore-evaluator` | `$.verdict` | `$.route`（`templates/wf-explore.json:41,214`；仅收口节点 `:336` 用 `$.verdict`） |
| `review` | `$.verdict` | `$.route`（`templates/wf-construction-full-feature.json:40,144,208,301,385`、`wf-diagnose.json:52,122,167,222`） |

即：三条 preset 的字段路径全部与实际模板不符（`grep -rn outcomePath templates/*.json`：`$.route` 14 处、`$.status` 3 处、`$.verdict` 1 处，共 18 个 `outcomePath` 声明）。该文件目前**在 `src/` 零引用**，所以今天没有实害；一旦接选择器，就是把错默认值直接交给用户。同向旁证：`docs/tasks/specs/LOC-016-logical-run-ui/requirements-analysis.md:97` 早已把这条列为附带发现并建议"另立小票收敛"。

🟢 建议：不论下面选哪条，先立一张 CHORE 小票把 preset 数据与实际模板对齐（纯数据修复，不占载荷、不动契约）。

## 3. 为什么必须现在决定

- #75 §4 明确把"Preset + 自定义字段路径"列为 v0.1 编辑器的正式能力，且是产品经理点名"仍在规划阶段"的项（原话理由："还有部分需求仍在规划阶段，比如 preset 等"）——这正是 #75 保留推进的主要理由，不能默认顺延。
- 配置负担是真实的：现在"结果与去向"层靠**手填字段名**（`client.js:1917-1931`，`$.` 前缀归一），字段候选由当前 schema 穷举得出，**不读 preset**。中文标签（"需优化，回执行"/"证据不足（可为合法完成）"）目前无处承载。
- 载荷预算贴线（余量约 1.6KB）——加选择器几乎必然要求配套瘦身，这是投入的真实成本，不能按"加个下拉"估价。

## 4. 候选方案

**方案 A · 只修数据，不做选择器**
- 成本：最低（一张 CHORE 小票，改一个 JSON）。
- 收益：消除错默认值隐患；preset 文件回归"仅供人读参考"的真实定位。
- 风险：#75 §4 的 Preset 项实质不落地，需要显式标注"移出 v0.1"；用户仍要手填路径，配置错的可能性保留。

**方案 B · 修数据 + "结果与去向"层加 Preset 下拉（推荐）**
- 成本：中。改造集中在 `client.js` 的"结果与去向"层（`:1917-1931` 一带）+ preset 读取通道（宿主侧下发或构建期内联，后者直接吃载荷预算）；需附瘦身评估。
- 收益：兑现 #75 §4 与 P2/P3 的渐进式承诺——用户选业务场景即得正确路径、枚举值与中文标签，与已有的"一键补边/边存在性校验"（`client.js:1978`）串成完整体验。
- 风险：preset 覆盖不到的自定义路径必须仍然可手填（不能变成只允许预设）；preset 与实际 schema 冲突时须提示而非静默覆盖——"仅推荐、校验不强制"的口径要在界面上可见。

**方案 C · B + 允许用户自建/保存预设**
- 成本：高。新增用户资产的存储、i18n 与删除边界。
- 收益：服务重度自定义用户。
- 风险：与 P3"结构修改必须另存为自定义工作流"的边界纠缠（预设本质是结构片段）；v0.1 目标规格未要求，属范围外扩张。

## 5. 关闭判据

产品经理在 A/B/C 中择一；选 B/C 时须同时确认"载荷预算不因本切片上调，超出先瘦身"这一前提是否接受，以及 §2 的纠偏小票是否独立先走。

## 6. 产物

- 结论回写架构文档 §4.2（现标注"preset 接选择器前不得直接使用"）；
- 无条件产物：preset 数据纠偏小票（§2）；
- 选 B/C：S-2 施工卡基线（含选择器交互与冲突提示口径）。
