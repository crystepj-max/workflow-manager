## 1. 需求背景

同一轮 UI 交互更新拆出三份施工 handoff，本任务承接 H3——三切片的**收口切片**：在编辑器与运行页表面结构稳定后，统一角色长文本、浅深色与无障碍。

角色管理的功能面已经齐备（内置 / 自定义分区、来源 badge、内置只读、自定义编辑 / 复制 / 删除、角色详情、引用阻塞）。本任务解决的是**可用性问题**与**主题一致性**，不碰业务语义。

## 2. 用户问题（业务语言）

1. **不知道能不能改**：看到内置角色想改，不确定是否允许；也看不出某个角色来自哪里。
2. **列表被撑爆**：某个角色职责写了几千字，列表行被拉长，其他角色被挤下去，找角色变慢。
3. **深色下看不清**：深色主题出现深色背景配深色字；窄屏下按钮被工具条盖住；键盘焦点看不见。

## 3. 目标

1. 来源一眼可辨：内置 / 自定义在标题与行内均可识别；内置只读可复制，自定义可编辑 / 删除并显示引用阻塞。
2. 摘要与全文分离：摘要最多两行，全文在独立滚动详情中可读；连续长串不横向溢出。
3. 主题统一：编辑器、运行页、角色页共用同一套 A 编排台语义 token（浅 / 深成对）。
4. 对比度达标：正文 ≥ 4.5:1，非文本控件 ≥ 3:1；状态同时有文字与图形。
5. 窄屏与键盘可用：390×844 各表面可操作；Tab / Shift+Tab 可达、焦点可见、Escape 关闭并回收焦点。

## 4. 非目标

- 不改角色存储、内容、引用关系、删除规则与宿主 RPC 语义。
- 不加角色权限层；不把内置角色改成可直接编辑。
- 不改 FEAT-84 / FEAT-85 的业务路由、运行状态、模型 override 与模板数据。
- 不以缩字号、隐文字或降对比度解决窄屏拥挤。
- 不复活初版 B/C 视觉方向。
