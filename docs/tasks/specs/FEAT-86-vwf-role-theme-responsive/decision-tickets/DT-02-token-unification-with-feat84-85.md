## 冲突描述

FEAT-86 的 V-3 闸门要求**全源码零 `--dsw-alias-` 引用**（组件只走 `--vwf-*` 语义 token，主题自包含）。
而 FEAT-84 编排台（冻结契约：宿主 `--dsw-alias-*` 优先 + 浅/深兜底板，V-8 对比度证据按该口径实测）
与 FEAT-85 运行详情（排版基线对齐 DESIGN.md，同样采用宿主 alias）各自按其已批准契约使用了宿主 alias。

三任务分别单独施工时闸门各自全绿；合并后两种策略在同一源码中共存，86 的 V-3 原断言（全源码零 alias）必然失败。

- 编排台 / 运行详情域（FEAT-84/85 契约域）：保留既有宿主 alias 引用；全局锁定
  **不增长**（`aliasRefs ≤ 58`，集成基线实测值）。
- 该口径不改任何一域的已验收视觉行为；统一时按裁决一次性迁移。
