- [x] 主要业务规则明确 —— R1 每任务独立会话非 subagent；R2 并发=同时存活会话数；R3 会话退出才释放名额补位；R4 看门狗超时记受阻释放；R5 会话只产 release-event.json + 验收卡，不写批次报告
