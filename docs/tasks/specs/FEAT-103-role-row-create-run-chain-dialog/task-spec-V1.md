# 角色列表行创建入口与内置角色简介 + 运行详情链路弹窗与信息整合

## 1. 需求背景

FEAT-102 部署后继续对照原型（4178 / `prototype-v2`）验收的第四批差距。运行详情页信息架构整合为主，另含角色列表入口与内置角色简介内容。

## 2. 差距清单（原型 <> 现状，验收逐条对照）

| # | 原型如何 | 现状如何 | 验收项 |
|---|---|---|---|
| 1 | 内置角色**列表行**也有「基于此角色创建」入口，与自定义角色行一致 | 该入口仅在详情页有 | V-1 |
| 2 | 内置角色有一句话简介（定位与职责的 1~2 句提炼） | 内置角色未填写显式简介 | V-2 |
| 3 | 「查看完整经过」弹窗展示**整个任务执行的工作链路**；点选链路节点回到详情页，右侧当前结果切换为该节点信息 | 与原型不一致 | V-3 |
| 4 | 详情下方节点/结果区域信息与完整经过是同一信息的一体两面 | 两处重复展示 | V-4 |
| 5 | 左侧运行定位给概要，「详细」按钮展开全量信息（含工作空间区域内容） | 运行定位与下方工作空间区域信息重复 | V-5 |
| 6 | Formal Artifacts 在右侧当前结果的「结果」页签内 | 独立区块在页面底部 | V-6 |

## 3. 能力零回退约束

- FEAT-85：详情三页签（结果/检查/活动）、决策卡（WAITING_HUMAN 选项/理由/影响/锁定 + DT-01 受阻字段）、恢复卡（BLOCKED）、attempt 切换、扇出子任务与汇总呈现、返回列表保留筛选与位置、DT-01 受阻路径——**行为全部保持**；本任务整合其承载位置与入口。
- FEAT-86：角色来源识别、摘要显式优先且不写回原文、Escape 逐层关闭、焦点回收保持；V-2 只是给内置角色数据补显式简介，不改变「留空由职责生成」的规则与 content 不可改写语义。
- FEAT-84：编辑器行为保持（本任务原则上不触及编辑器）。
- 既有测试随布局调整同步修订选择器/mount；能力级断言不删。

## 4. 验收条件

- [ ] V-1 内置角色**列表行**提供「基于此角色创建」入口，行为与详情页一致（进入以该角色为初稿的新建表单，保存为自定义角色，不写回原内置角色）。
- [ ] V-2 每个内置角色具备 1~2 句「一句话简介」（从其详情描述提炼定位与职责），列表与详情展示该简介；后续新增内置角色沿用同一数据字段。
- [ ] V-3 「查看完整经过」打开弹窗展示完整工作链路（含尝试/返工轮次）；点选链路中任一节点关闭弹窗回到详情页，右侧当前结果切换并定位到该节点信息。
- [ ] V-4 原详情下方独立的节点/结果区域不再重复展示，其信息由链路弹窗与右侧当前结果承接，无信息丢失。
- [ ] V-5 运行定位默认展示概要；「详细」展开全量信息（含原工作空间区域内容），收起恢复概要。
- [ ] V-6 Formal Artifacts 移入右侧当前结果「结果」页签；工件列表/修订/来源节点信息完整，页面底部不再有独立区块。
- [ ] V-7 能力零回退：§3 全部约束成立；载荷预算不上调。

## 5. 风险

- 载荷预算余量仅约 2KB（当前 276491 / 上限 278528）：**本批必须先瘦身再增量**（优先清理整合后失去用途的样式/代码路径）；仍超限按 BLOCKED 释放，禁止自行上调预算（调整走人工裁决）。
- 运行详情布局整合涉及 85 的既有详情测试选择器大面积修订：能力断言不删。
