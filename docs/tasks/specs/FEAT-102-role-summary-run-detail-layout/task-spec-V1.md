# 角色简介选填属性、内置「基于此角色创建」、运行详情布局照原型

## 1. 需求背景

FEAT-101 部署后继续对照原型（4178 / `prototype-v2`）验收的第三批差距。呈现层与表单属性级对齐，不改 RPC、数据契约与执行语义。

## 2. 差距清单（原型 <> 现状，验收逐条对照）

| # | 原型如何 | 现状如何 | 验收项 |
|---|---|---|---|
| 1 | 内置角色也有「**基于此角色创建**」按钮（文案与位置照原型） | 内置角色创建入口文案/形态与原型不一致 | V-1 |
| 2 | 角色新建/编辑表单含「**一句话简介（选填）**」字段；填写后用于角色列表简要介绍 | 表单无该可选字段（列表摘要仅由职责生成或既有显式值） | V-2 |
| 3 | 运行记录详情页**布局照原型**（工作空间层内的分区、排版、信息层级与原型一致） | 详情布局与原型不一致 | V-4 |

## 3. 能力零回退约束

- FEAT-86：来源识别（builtin 布尔）、**摘要显式优先且不写回原文**、详情完整职责独立滚动、Escape 逐层关闭（二次确认→详情/表单→列表）、焦点回收保持。
- 「一句话简介」语义：显式填写优先展示；留空时沿用既有「由职责生成摘要」规则；该字段仅用于展示，不改变角色职责内容（content）本身。
- FEAT-85：运行列表分组/筛选/返回保留位置、详情三页签、决策卡/恢复卡、attempt 切换、DT-01 受阻路径呈现保持；本任务只改详情页布局与排版。
- FEAT-84：编辑器行为保持（本任务原则上不触及编辑器）。
- 既有测试随呈现调整同步修订 mount/选择器；能力级断言不删。

## 4. 验收条件

- [ ] V-1 内置角色提供「基于此角色创建」按钮，文案与位置与原型一致；点击进入以该角色为初稿的新建表单，保存为自定义角色，不写回原内置角色。
- [ ] V-2 角色新建/编辑表单提供「一句话简介（选填）」输入；显式填写优先展示于列表；留空时由职责生成摘要；保存后职责原文不被改写。
- [ ] V-3 角色列表行展示一句话简介（显式值优先）；两行收敛与断词样式保持。
- [ ] V-4 运行记录详情页布局与原型一致（分区/排版/信息层级对照 prototype-v2 的 run 详情形态）；详情全部既有行为（三页签、决策卡、恢复卡、attempt 切换、返回列表保留筛选与位置）保持。
- [ ] V-5 能力零回退：§3 全部约束成立；载荷预算不上调。

## 5. 风险

- 载荷预算余量约 5.1KB（当前 273384 / 上限 278528）：优先复用与瘦身；超限先瘦身，禁止自行上调（调整走人工裁决）。
- 运行详情布局改版涉及 85 的既有详情测试选择器修订：能力断言不删。
