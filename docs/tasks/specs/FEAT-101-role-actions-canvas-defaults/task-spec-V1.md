# 角色页操作语义与编辑器画布/全局参数布局对齐原型

## 1. 需求背景

FEAT-100 部署后继续对照原型（4178 / `prototype-v2`）验收的第二批差距。同为呈现层对齐，不改 RPC、数据契约与执行语义。

## 2. 差距清单（原型 <> 现状，验收逐条对照）

| # | 原型如何 | 现状如何 | 验收项 |
|---|---|---|---|
| 1a | 角色列表页**右侧**有「新建角色」按钮 | 新建入口位置与原型不一致 | V-1 |
| 1b | 内置角色提供与自定义角色一致的「**基于角色创建**」入口 | 内置角色缺该入口 | V-2 |
| 1c | 内置角色=**查看**、自定义角色=**编辑**，各只有一个入口，不并列「查看+编辑」 | 存在查看/编辑双入口 | V-3 |
| 1d | 角色详情页有**一句话简介** | 详情页缺简介展示 | V-4 |
| 2a | 工作流**全局参数配置**在左下角（节点选择面板下方），两个面板 **6:4** 竖向分割 | 全局参数不在该位置 | V-5 |
| 2b | 画布**默认就近清晰展示节点**（可看清节点内容），而不是缩小展示整个工作流；节点很多时用户可自行缩小 | 默认 fit 全图，节点多时太小 | V-6 |
| 3 | 内置工作流**模型设置**的呈现与交互照原型 | 与原型不一致 | V-7 |

## 3. 能力零回退约束

- FEAT-84：V-2 位置感、V-3 渐进披露、V-6 撤销历史、V-7 内置结构只读+模型设置能力（默认/覆盖/单节点还原/全部还原）、V-13 连接弹窗等**行为保持**；画布默认缩放值变化不构成回退（缩放/拖拽/适配能力不变）。
- FEAT-86：角色来源识别（builtin 布尔）、摘要不写回原文、详情独立滚动、Escape 逐层关闭、焦点回收**保持**；「内置可复制/基于创建、不可编辑/删除」的权限边界保持——本任务只是把入口形态对齐原型（内置用「基于角色创建」承载复制语义）。
- 既有测试随呈现调整同步修订 mount/选择器；能力级断言不删。

## 4. 验收条件

- [ ] V-1 角色列表页右侧有「新建角色」按钮（与原型位置一致）。
- [ ] V-2 内置角色行/详情提供「基于角色创建」，点击后进入以该角色内容为初稿的新建表单，保存为自定义角色；不写回原内置角色。
- [ ] V-3 内置角色单一入口「查看」；自定义角色单一入口「编辑」；不再并列查看+编辑。
- [ ] V-4 角色详情页展示一句话简介（summary）；缺失时按既有规则由职责生成展示，不写回原文。
- [ ] V-5 编辑器左列为 节点选择面板（上，6）+ 全局参数配置（下，4）的 6:4 竖向布局；全局参数配置含既有全部字段且保存行为不变。
- [ ] V-6 画布打开默认就近清晰展示节点（入口段可读），不强制 fit 全图；缩放/拖拽/适配按钮与位置感（84 V-2）保持。
- [ ] V-7 内置工作流模型设置的呈现与交互与原型一致；默认/覆盖/还原能力与校验行为不变。
- [ ] V-8 能力零回退：§3 全部约束成立；载荷预算不上调。

## 5. 风险

- 载荷预算余量约 6.4KB：优先复用组件与样式、优先瘦身；超限先瘦身，禁止自行上调（调整走人工裁决）。
- 画布默认缩放改动影响 84 的首屏取证口径：按新默认重取证据，不视为回退。
