## 摘要（三要素速览）

### 任务目标

让验收清单成为**照着执行不会产生假红灯**的清单：每条验收项声明「执行时机」（裁决前可观测 / 收口后观测），两类分区呈现，收口后项必须被实际执行并回填结果，定义阶段的检查清单能拦住未声明时机的项。

### 涉及范围

- 做：
  - 规则 R-1～R-9 落入 5 处真源 + 执行手册：`uat-card-template.md`、`task-spec-template.md`（§16/§18）、`definition-check.md`（§9.5）、`single-task-delivery-m2.md`（§5/§7）、`public-task-contract.md`（§6）、`dsh/skills/construction-bootstrap/runbook.md`（§5/§7）
  - UAT 卡模板结构升级：「执行时机」字段 + 独立分区「收口后复核」（含结果回填表）+ 总览区裁决依据声明
  - 一条最小机器断言（M2 机械检查：验收卡模板必须含「执行时机」字段，只测存在性）+ 一条负例测试
  - 副本对齐：`task-spec-template.md` 的两份副本（当前已漂移一行），并锁定另两对副本全等
- 不做：
  - 不改人工验收三态与其流转、不改自动返工上限 3、不改 `handoff.schema.json`、不把「收口后复核」升为 M2 主链状态机节点
  - 不做按自由文本逐条解析验收项的校验器
  - 不追溯回改历史卡与历史规格（含已归档的 LOC-020 / LOC-023）
