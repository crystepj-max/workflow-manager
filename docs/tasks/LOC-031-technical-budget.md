## 摘要（三要素）

**目标：**失败后的最大自动消耗可解释、可配置且有限，技术问题不吞掉业务返工额度。

**范围：**四模板自动调用次数、技术失败等待、运行时间、恢复预算及用户受阻提示。 不扩大业务自动返工额度，不引入 Temporal 或队列服务，不在未知价格下承诺实际货币硬上限。

**验收标准：**

- [ ] AC-01：持续无效输出最多调用 3 次即停止；内部格式修复和技术自环不能各自偷偷获得额外 3 次。
- [ ] AC-02：暂时错误按可控时钟验证退避；不可重试错误最多调用 1 次即停止；超时后停止发起新调用并尽力取消当前调用。
- [ ] AC-03：业务返工计数不因技术重试增加；同一受阻 Run 恢复不重置已耗预算，人工明确新技术额度后才能继续。
- [ ] AC-04：相同目标的无进展重新确认连续 2 次后受阻；真正的新目标/新基线不被误判。
- [ ] AC-05：用户可查看冻结的次数/时间限制及实际消耗；无法强制终止的外部调用标明取消能力限制。
