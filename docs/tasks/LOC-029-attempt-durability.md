## 摘要（三要素）

**目标：**每次真实节点调用都有独立、可恢复且不重复的执行记录，节点最新结果只是索引。

**范围：**全部模板的逐次调用记录、宿主存储、结果查询与中断恢复。 处理本地执行及正式记录持久化；外部发布等副作用幂等由 WR-012 负责，完整事件溯源平台不在范围内。

**验收标准：**

- [ ] AC-01：复现的 8 次调用留下 8 个完成 attempts；3 次评估各有可读结果和正式 Revision，最新索引指向第 3 次。
- [ ] AC-02：同一节点跨 segment 再次执行也追加记录；fanout 不同专家与轮次不会碰撞。
- [ ] AC-03：在结果落盘后、确认前及索引更新前分别注入中断，恢复后已确认结果不丢失且不重复生成 Revision。
- [ ] AC-04：模拟写盘失败、重复提交和并发提交，均不能显示“证据有效且完成”却缺少记录；失败可恢复。
