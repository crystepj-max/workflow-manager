## 摘要（三要素速览）

### 任务目标

让「终态任务的工作区何时必须清理」在文档与机器校验器之间**只有一个答案**，并让校验器在主检出与任一链接工作树内给出**同一组结论**；收口时自动删除工作区（保留分支），使 `npm run validate` / `npm run release:verify` 在正常交付节奏下可全绿。

### 涉及范围

- 做：
  1. 口径收敛：修订 6 处交付链文字 + 1 处测试断言，统一为「托管暂停期**删工作区、留分支**」（判据：工作区可再生 / 分支不可再生）；
  2. 校验器定位修正：`scripts/validate-workspace.mjs` 分离「锚点（数据来源 = 主检出）」与「被校验集合（排除主检出的全部工作区，含调用方自身所在工作树）」；
  3. 例外区补齐：`EXEMPT_PATH_SEGMENTS` 增补 `.codex/worktrees`（约定 §1.10 外部运行时）；
  4. 收口动作补齐：`scripts/local-task-merge.mjs` 在证据锚定与摘要生成之后自动删除本任务工作区，并自动写入 `branch_retained = true`；
  5. 数据补齐 + 存量清理：补 LOC-014 / LOC-019 的 `branch_retained`；删除 `dev-loc-014-r1`、`dev-loc-019-r1` 两个终态工作区（保留分支）；
  6. 回归用例：见规格 §15。
- 不做：不改 `.generated/` / `.agent-runs/` / `.task-runs/` 不入库口径；不处理 GitHub / CNB 凭据（另案）；不动 LOC-021 异源档位范围；不改动在制任务工作区（LOC-020 / LOC-021）；不删除 `/Users/chris/.codex/worktrees/**`；不引入新的定时任务。

## 背景（矛盾证据，2026-09-14 实测）

| 规则 | 内容 | 后果 |
|---|---|---|
| 决策 `0001` 第 6 条 + 约定 §1.5 / §1.7.1 / §1.7.2 | 托管暂停期「**删工作区、留分支**」；判据「工作区可再生、分支不可再生」 | 权威口径 = 终态即删工作区 |
| 交付链 6 处文字（runbook `:206`、公共契约 `:270` ×2、离线轨道 `:177`、`docs/tasks/README.md:36`、`local-task-merge.mjs:17/:347` + 测试断言 `:177`） | 「工作区与分支**暂不删除**」 | 与 0001 相悖的**文档漂移**；按文字执行 → 闸门必红 |
| `validate-workspace` D-7 | 「终态任务（已合并/已取消）工作区已清理」 | 与 0001 一致，但被判为「与文字冲突」 |

实测：主检出侧 `npm run validate:workspace` 失败 2 项（D-2 ❌1 为 Codex 工作区被误判治理区；D-7 ❌2 为 LOC-014 / LOC-019）；链接工作树侧额外多出 D-2 ❌2 / D-3 ❌1 / D-4 ❌1（主检出被当作工作区）、D-5 ➖ 跳过、D-7 只报 1 项（读分支内旧登记册：终态 16 vs 17）。`node scripts/validate.mjs` 与 `npm test` 均通过 → 工作区闸门是发布闸门的**唯一**阻塞原因。

## 已确认的关键决策（2026-09-14，松哥）

| 决策 | 选择 | 原因 |
|---|---|---|
| 口径归属 | **A · 对齐决策 0001 第 6 条与约定 §1.7：收口即删工作区、只留分支** | 判据已定死答案；保留工作区对补 PR 无增量价值；方案 B/C 均等于推翻已接受决策 |
| 收口删工作区执行方式 | **A1 · 合并脚本自动删除**（四项前置 + 禁用 `--force`，失败仅登记遗留） | 人工执行会使闸门在人工动作前保持红色，无法满足正常交付节奏全绿 |
| Codex 外部运行时工作区 | **A · 纳入例外区**（`.codex/worktrees`） | 与 `.cursor/worktrees` 先例一致（约定 §1.10）；不纳入则 D-2 恒红 |
| `branch_retained` 写入 | **A · 合并脚本自动写入** | 该字段无脚本写入导致 D-10 静默跳过（实测仅覆盖 13/16） |
| 无人值守许可 | 允许 | 无「施工时再决定」的产品问题；删除动作边界由 R-4 固定 |
| 体量 | M（单切片，不拆分） | 两侧缺陷改同一函数同一文件，拆分只引入串行与重复改动 |

原卡 3 个待决策点已全部关闭；其中「保留期与证据期的关系」因决策 1 选 A 自然消解（工作区不设保留期，仅证据明细保留 7 天）。
