## 摘要（三要素速览）

### 任务目标

按规格 §13 发布门槛完成 v0.1 产品模式最终验收：关闭开发 DSH → `npm run release:verify` 重建正式产物 → 完整重启产品 DSH → 从真实安装路径加载正式插件 → 完成全部真实工作流 E2E 与本版本功能验收。开发模式 / External Profile / 机器闸门通过都不等于 Release Ready。

### 涉及范围

- 做：产品模式 E2E 清单执行与证据留档——四套正式模板（建设 / 优化 / 诊断 / 探索）关键正常 / 回退 / 人工 / 不足路径；多 Run 同仓并行隔离；Integration Checkpoint 与 Proof 版本绑定；探针失败 → BLOCKED → 改模型恢复；Logical Run 跨段恢复；Skill/Chat 入口。发现缺陷不在本卡修：回对应 LOC 修复后，候选版本作废，按"回开发模式 → 重新生成 → 重新闸门 → 重启产品 DSH → 重新全量验收"重来。
- 不做：任何新功能；手改正式产物。

### 验收标准

- [ ] 规格 §13 发布门槛清单逐项通过并留证据（含四模板 E2E、多 Run 并行、Integration、Proof 绑定、恢复、入口）
- [ ] `npm run release:verify` 通过 + 产品模式人工 E2E 通过（双证据）
- [ ] Current/Target 文档边界同步完成（`CONTEXT.md` 等待新语义入 main 后的重写项核对）
- [ ] 旧 Built-in 资产迁移无用户引用丢失（default-workflow / dev-workflow-2-0 / dispatcher 可解析）
