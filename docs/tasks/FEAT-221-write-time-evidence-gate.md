## 摘要（三要素速览）

### 任务目标

让「签收」和「收口」这两个契约明确要求校验的时刻，在记录落盘前自动跑一遍证据链整链校验；不通过就拒写。忘记执行命令不再等于跳过校验。

### 涉及范围

- 做：`cwf-record` 在 `acceptance_package`（`decided` 形态）与 `closeout_summary` 两处写入前调用引擎；失败拒写、不落盘、不更新 `index.json`；打印未通过项（与独立 CLI 同构）；runbook §6 人工步骤降为兜底说明；负例先行。
- 不做：其余五类记录不加校验（此时链路本就不齐）；不新增「告警放行」或 `--force` 旁路；不改引擎判定语义；不做 CI 侧强制。

### 验收标准

V-1~V-8（规格 §15）：整链不成立时签收被拒且**无记录文件、index 未更新**；整链通过时行为与之前完全一致；closeout 引用坏包被拒；`awaiting_decision` 不触发（固定为正例防全量触发）；缺引用文件不得静默放行；`npm test` 全绿。
