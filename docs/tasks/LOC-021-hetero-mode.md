## 摘要（三要素速览）

### 任务目标

编辑器工作流控制区提供「关 / 弱 / 强」三档异源要求并随蓝图真实生效：弱档（默认）等同现状、强档要求 provider 必须不同、关档不做校验；旧蓝图行为零变化。

### 涉及范围

- 做：
  1. 档位字段三态化 + 旧数据兼容读入（缺失或旧值 `true` → 弱；旧值 `false` → 关）；
  2. 校验内核按档位判定（关 / 弱 / 强三套语义，仍只拦「开发↔审核」一对）；
  3. 蓝图 ↔ 编辑视图三态双向透传；
  4. 现有 ON/OFF 开关升级为三档选择器 + 中英文案同步；
  5. 运行时异源日志识别口径统一为「按节点 id 或角色」并输出当前档位（修复诊断模板日志不触发）；
  6. 四套内置模板显式声明弱档；
  7. 契约文档同步修订（字段语义 / 硬规则条款 / 等价性检查清单 / 决策票）与测试补齐。
- 不做：扩大校验配对范围（不纳入「开发↔测试」「执行↔评估」）；节点级或按配对分别配置档位；运行中切档；默认模型绑定调整（归 LOC-019）。

### 验收标准

- [ ] 编辑器提供「关 / 弱 / 强」三档选择，保存后蓝图携带所选档位、重开不丢
- [ ] 强档：开发与审核同 provider（即使 model 不同）→ 保存与发起运行均被拒，错误含实际值、档位说明与修复指引
- [ ] 弱档（默认）：同 provider 不同 model 通过 + 弱异源警告；provider 与 model 完全相同被拒
- [ ] 关档：开发与审核完全同模型 → 不校验、可保存、可运行
- [ ] 旧数据兼容：缺失或旧值 `true` → 弱档；旧值 `false` → 关档；非法值按弱档处理并报错
- [ ] 诊断模板在弱档下的运行时异源日志正常输出并按档位给结论
- [ ] 未扩大配对范围：「开发↔测试」「执行↔评估」同模型不被拦截
- [ ] 契约文档已同步修订；四套内置模板显式声明弱档
- [ ] 插件包测试 + `npm test`、`npm run validate`、`npm run release:verify` 全绿
