## 摘要（三要素速览）

### 任务目标

把模板编辑从「小设置弹窗里的长表单」改造为**两层表面的编排台**：小设置入口负责找模板、看摘要；「编辑 / 查看并验收」打开独立大工作区。用户查看分支、回环、扇出与结果去向时，**右侧配置栏单独滚动，不再把画布带走**；并且先用业务词（步骤、负责角色、交付内容、结果与去向）理解流程，需要时才展开技术细节。

### 涉及范围

- 做：
  - 保留「小设置入口 → 大工作区」两层表面；关闭工作区后回到原列表位置、筛选与滚动位置
  - 大工作区采用 A 编排台三段结构：左侧步骤定位区、中间路线画布、右侧单一节点配置栏
  - 画布 / 配置栏 / 连接清单**各自滚动**；工作区头部与保存、返回操作常驻可见
  - 节点配置栏改为渐进披露：`基础（任务 / 负责角色 / 交付内容）` → `结果与去向` → `高级设置 / JSON`
  - 多结果业务路由、业务回环、扇出后汇总的完整呈现；连接清单区分「普通业务路由 / 业务回环 / 调用重试」
  - 保留 `↶` / `↷` 撤销与反撤销的既有历史语义（禁用态、连续输入合并、撤销后新修改清空重做分支）
  - 保留既有「选中节点 → 供应商与模型」入口；内置节点默认 / 覆盖 / 单节点还原 / 全部还原作为**兼容检查项**
  - 浅色、深色、键盘焦点、Escape 关闭、390×844 窄屏达到同一可读性
- 不做：
  - 不改工作流执行引擎、编译器、模板业务语义或回环计数规则
  - **不新增自定义模板的模型默认 / 覆盖 / 全部还原产品规则**（该层级只对内置模板存在）
  - 不把运行详情、人工决策、BLOCKED 恢复逻辑塞进编辑器（属 FEAT-85）
  - 不重做角色存储、角色引用、供应商注册或模型列表后端（角色表面属 FEAT-86）
  - 不以原型中的示例运行、个人模板或角色内容作为生产数据

### 验收标准

- [ ] V-1 小设置入口可打开大工作区；关闭后保留原列表、筛选与滚动位置
- [ ] V-2 右侧配置栏滚到底部时，中央画布仍可见、可选节点、可缩放、可查看连接
- [ ] V-3 不阅读 JSON 即可完成「新增节点 / 配置负责角色 / 配置交付内容 / 设置结果去向」
- [ ] V-4 至少验证一个多结果模板、一个有业务回环的模板、一个扇出后汇总的模板；连接清单不漏边
- [ ] V-5 调用重试、业务回环、返工轮次使用不同标签与说明
- [ ] V-6 `↶` / `↷` 禁用态、撤销后新修改清空重做分支、JSON 与画布共用历史均通过
- [ ] V-7 内置模板节点结构不可编辑；内置节点可进入既有供应商 / 模型设置并验证默认 / 覆盖 / 单节点还原 / 全部还原；自定义模板无默认 / 覆盖入口
- [ ] V-8 浅色与深色均无「深色背景 + 深色字」；正文对比度 ≥ 4.5:1，控件边界 / 图标 ≥ 3:1
- [ ] V-9 390×844 下无横向溢出；焦点不被底部操作条遮挡；Escape 能关闭当前工作区或对话框
- [ ] V-10 自动测试、浏览器截图与正式 DSH 验收分别记录，不用原型截图替代生产验收
