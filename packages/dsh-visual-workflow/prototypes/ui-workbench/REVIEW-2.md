# 第二轮：补齐真实工作流场景

状态：交互原型已更新，待用户体验反馈。用户倾向编排台，本轮模板工作区与运行详情统一使用 A；不代表正式产品需求或实现已验收。

## 本轮问题与原型回应

| 用户关注 | 当前原型 |
| --- | --- |
| 内置模板不可编辑，但允许模型设置 | 任务与分支只读。每个节点独立设置供应商 / 模型，显示「默认 / 覆盖」，支持单节点或全部还原各自预设。内置与个人模板的节点配置顶部均有入口；取消模型弹窗不应用草稿。 |
| 能否从零创建 | 可以。新建提供「从零搭建」和「复制已有模板」；后者包含内置及个人模板。空白模板从一个起始步骤开始，可添加步骤与不同结果去向。 |
| 五套个人模板如何展示 | 预置五套清楚标注为示例的个人模板；全部 9 / 内置 4 / 我的 5 分区、搜索、逐行展示，内容区独立滚动。创建后加入「我的」，支持重新打开、编辑、保存与复制。 |
| 回环、多种业务结果 | 从实际模板读取全部连接；画布可切换全图 / 所选步骤，每条结果可打开说明；「结果与去向」展示一个步骤的所有分支，「连接清单」逐条核对。调用重试单独开关，不与业务返工混淆。 |
| 并行研究 | 「独立研究」显示为一个并行组，展开三个视角示例；实际模板要求 3–5 人，按上一步任务书分配。每位研究员分别执行、保留报告，全部结束后交给汇总；补充研究返回「安排研究」。 |
| 多空间、多任务 | 预置 3 个工作空间的 8 条任务；按空间分组、空间筛选、待处理 / 进行中 / 已完成筛选；每条显示模板、当前状态、返工数与时间。打开详情后返回原列表与筛选。 |
| 多轮返工 | 目录与画布显示每步执行次数；右侧选择第几次执行，成果与意见不混用；完整经过按发生顺序展示。新增模拟退回会追加记录并保留输入意见。返工前已完成的下游步骤标记为上一轮成果。 |
| 内置与自定义角色 | 分区筛选、来源标记；内置只读，可复制；自定义可编辑。 |
| 长角色职责撑开列表 | 独立的一句话简介；未填写时从完整职责截取两行。长串自动换行，列表保留编辑入口；完整内容放在可滚动的独立详情里。 |

## 已查证的当前实现

- `src/client.js` 的 `Skeleton()` 与 `onNew()` 已提供从空白骨架开始的路径；不是只能从内置模板复制。
- `src/client.js` 的 `ovRows()` 实际界面为每节点一行：供应商、模型、默认 / 覆盖和单节点还原。内部兼容 `$default` 不代表界面应增加整套流程模型层级。此前原型将内部兼容结构误读为交互要求，已按用户反馈纠正。原型只模拟交互，不调用真实保存接口。
- 模板所有连接直接来自当前检出的 `templates/`，原型服务仅补充读取节点类型、模型绑定和轮次限制。

| 模板 | 业务连接 | 调用重试 | 明确标记计次的业务回环 |
| --- | ---: | ---: | ---: |
| 完整功能开发 | 16 | 6 | 2 |
| 诊断与修复 | 13 | 5 | 4 |
| 多视角探索 | 7 | 3 | 1 |
| 快速优化 | 10 | 4 | 1 |

人工退回等连接并不都带 `countRound`。画布仍展示这些连接，不将“连接数量”“返工次数”和“调用重试”混为同一件事。

## 本轮检查

检查方式为真实浏览器点击、输入、截图和只读页面测量，未添加正式测试套件。

- 内置模板任务字段不可编辑；此前整体模型设置检查仅为第二轮旧原型的历史记录，已由下方逐节点检查替代。
- 从零创建一个步骤，再增加第二步与另一种结果去向，保存后可在个人模板列表找到。
- 完整功能开发画布 16 条业务连接；诊断修复打开调用重试后共 18 条连接，其中 5 条重试、4 条业务回环。
- 诊断审查有四种结果：检查通过、修复仍有问题、原判断不成立、暂时无法继续。
- 多视角探索有一个并行组、三个独立子任务示例、7 条业务连接与补充研究回环。
- 工作空间筛选只显示所选空间任务；待处理筛选初始显示 3 条任务。
- 历史中可看到实现第 1 次 → 审查退回 → 实现第 2 次 → 审查通过；切换第 1 / 2 次时显示对应版本。唯一详情区数量为 1。
- 再做一次模拟人工退回，输入意见保留在时间线，并新增实现第 3 次的当前记录。
- 无简介且职责包含 4,537 字与连续长串时，正文只占两行（39.59px），角色行高约 127px，全页没有横向溢出。
- 390×844 窄屏：设置弹窗宽 374px；运行验收按钮区底部 738px，正好位于原型工具条上方，无全页溢出。
- 沿用 A 的深浅语义色，复查浅色编辑与深色运行、窄屏文字和控件。初版核心配色检查仍见 `evidence/contrast.json`，不是完整无障碍认证。

## 交付边界

### 2026-09-17 小范围修订

- 移除整套流程模型默认层。内置预设直接读取模板的节点绑定，例如开发为 `deepseek-flash`、审查为 `deepseek-v4-flash`；新建空白节点采用 DeepSeek / `deepseek-flash` 示例预设。
- 内置与个人模板均在节点任务配置顶部展示当前供应商、模型、默认 / 覆盖状态和设置入口。内置保存只影响该节点模型；个人节点设置随模板保存，并纳入撤销 / 重做。
- 编辑工具栏使用向左 / 向右箭头表示撤销 / 重做，无记录时禁用；撤销后进行新修改会清空旧重做分支。
- 本轮实际浏览器检查：内置审查节点单独修改模型、保存后回读；开发节点切换供应商后联动模型；单节点还原；全部还原恢复各节点不同预设；个人节点模型与名称连续撤销 / 重做；撤销后新增修改禁用重做；保存后返回流程库重新打开，节点模型和名称一致。深色模型弹窗与浅色个人编辑器已截图复查，语法检查通过，页面错误日志为空。

这仍是一次性 UI 原型：内置定义来自源码；个人模板、角色、供应商选项、研究子任务与运行记录是示例。编辑仅保留在内存，刷新恢复初始内容。运行记录用于展示交互，不是实际执行引擎；不会连接真实 DSH、创建真实任务或提交人工验收记录。

本轮没有修改正式插件源码与模板，没有提交或推送。初版设计仍可通过 `version=1` 对照；原型不能直接作为生产实现合入。
