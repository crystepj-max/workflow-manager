# issue-58 · 工作流角色库：区分内置与自定义角色，支持创建、编辑、复用与安全删除

## 需求摘要

编辑器此前只有「角色选择器」（`vwf.roles` 列出工作区 `dsh/roles/*.md`），没有角色资产
管理能力。本需求建立统一「角色库」：

- **内置角色**（系统标准模板，`dispatcher/dev/test/review/accept/closeout`）常驻、
  只读：可查看、可选择、可「基于此角色创建自定义角色」，不可修改/删除/覆盖；
- **自定义角色**（用户资产）支持 空白新增 / 基于内置创建 / 基于自定义创建、
  编辑、安全删除；
- 名称全局唯一（内置 + 自定义，大小写不敏感）；被引用的角色禁止删除（无强制删除）、
  禁止重命名；修改被引用角色前提示影响范围；修改后所有引用位置全局生效（引用按 id）；
- 画布右上角「角色库」常驻区（胶囊）固定提供「管理角色」「＋ 新增角色」入口，不随
  自定义角色数量变化；节点配置的角色选择区分内置/自定义分组；
- 角色库变更后新建角色立即进入节点选择器（无需重开编辑器）。

## 实现要点

### 数据模型与运行时契约

自定义角色 = 工作区 `dsh/roles/<名称>.md`（与运行时
`profile → <roleDir>/<id>.md` 的既有消费契约一致：保存即被 `wf_run` 编译产物按原
机制读取，**无需**运行时/生成器改造）。内置角色有独立元数据（名称/摘要），正文优先取
工作区文件，缺失时回退打包仓库 `__VWF_REPO__/dsh/roles`，再回退元数据合成占位正文。

引用统计 = 全部工作流（内置模板 `.generated` + 用户模板 `~/.dsh/visual-workflow/templates`）
节点 `profile` 命中该角色 id 的计数，按工作流分组返回引用位置详情。

### Host RPC（`src/host.js`）

| RPC | 行为 |
| --- | --- |
| `vwf.roles` | 升级：内置六角色常驻置前（`builtin: true`）+ 自定义角色（`builtin: false`），保留 `{id,name,summary}` 供选择器使用 |
| `vwf.roles.get` | 单个角色详情（含 `content` 正文），内置只读查看数据源 |
| `vwf.roles.usage` | 引用计数 + 按工作流分组的节点引用位置 |
| `vwf.roles.create` | 名称校验（非空/64 字符/文件系统安全字符/首尾点）→ 唯一性（内置+自定义，大小写不敏感）→ 落盘 `dsh/roles/<name>.md` |
| `vwf.roles.update` | 仅自定义；内容修改直接放行（引用按 id 全局生效）；**重命名仅零引用放行**（服务端强制，防引用失效）；内置拒绝 |
| `vwf.roles.remove` | 仅自定义；被引用 → 阻止并返回 `usage` 详情（无强制删除）；内置拒绝 |

写盘走 `writePolicy()`（与用户模板/runs 落盘一致），删除经子进程 `rmSync`（fs 服务无删除面）。

### Client UI（`src/client.js`）

- **角色库常驻区**：画布工具栏右侧胶囊（`.vwf-role-zone`），常驻「管理角色」「＋ 新增
  角色」入口；**节点配置角色选择**：`VwfSelect` 增加 optgroup 分组（内置/自定义），
  保留「当前值不在清单」的兜底展示。
- **角色管理浮层**（覆盖在编辑器之上，节点草稿不丢失）：
  - 列表：内置/自定义分区（内置行徽标 accent），自定义行 编辑/删除，底部「＋ 新增角色」；
  - 查看（内置）：只读正文 + 「基于此角色创建自定义角色」（预填 `来源名 - 自定义`）；
  - 创建/编辑表单：名称 + 配置（Markdown），重名/空内容/非法字符客户端预检；
  - 删除：先查引用——有引用弹「无法删除」+ 引用位置详情（工作流/节点），零引用二次确认；
  - 编辑被引用角色：保存前弹影响范围确认（N 个节点共同使用新配置）；
  - 所有变更后回调 `onRolesChanged` → Page 重拉 `vwf.roles` → 节点选择器即时刷新。

## 删除/重命名保护规则

- 被任意工作流（含内置模板）节点引用的自定义角色：**禁止删除**，提示仍被 N 个节点使用及
  引用位置；**禁止重命名**（重命名会使按 id 的引用失效）。
- 内容修改不受引用限制，保存前 UI 提示影响范围，确认后全局生效。
- 内置角色：查看/选择/基于其创建变体；修改与删除均在服务端拒绝。
