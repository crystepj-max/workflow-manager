`capture-metrics.json` 为程序化度量，核心断言包括：

- 任意两个按钮的包围盒重叠面积为 0；
- 提示文字与按钮无重叠；
- 按钮文字没有横向裁剪（`scrollWidth <= clientWidth`）；
- 按钮完整位于操作区内；
- 画布从操作区下边界之后开始，操作区增高不会遮住画布；
- 操作区无横向溢出。

度量结果：`passed = true`（4/4 视口全部通过）。
