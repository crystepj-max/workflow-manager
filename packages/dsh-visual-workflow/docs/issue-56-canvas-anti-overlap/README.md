`capture-metrics.json` 为程序化度量，核心断言包括：

- 任意节点主体包围盒不重叠；
- 边标签按真实浏览器文字包围盒检测，不落在任何节点主体内部；
- 同起点/终点的多条边标签坐标会错开，不明显叠合；
- 正交绕行边的线段不穿过无关节点；
- 每个复杂场景至少存在一条外围车道路径；
- 全部场景 `passed = true`。

## 产出方式（可复现）

使用 `.scratch/pw-env/` 中的本地 Playwright/esbuild 验收环境（该目录已被 Git 忽略）：

1. 将当前 `packages/dsh-visual-workflow/src/client.js` 包装进浏览器 harness；
2. 用真实 Chromium 打开编辑器；
3. 分别注入「跨节点 + 失败回路」与「上下分支 + 失败回路」两组 DSL；
4. 读取节点、边路径和边标签坐标，执行重叠/穿越检测并导出截图。
