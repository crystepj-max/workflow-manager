# 04 — 新增通用角色 requirements（需求分析）与 designer（方案设计）

**What to build:** 新增两个通用内置角色。`requirements` 负责把模糊诉求加工成可执行的需求（含目标、范围、验收三要素），`designer` 负责把已确认的需求转化为可实施的方案。两者都能在角色库「内置」分组中看到、可被流程节点引用、不可编辑但可基于其创建自定义变体。

**验收依据**：这两个角色是为「建设 · 完整功能开发」流程准备的（`requirements` 对应需求分析节点、`designer` 对应方案设计节点）。需说明它们的多个可复用场景，而非只服务单一流程。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 角色库「内置」分组出现 `requirements`（中文名：需求分析）与 `designer`（中文名：方案设计）
- [ ] 两者均不可编辑、不可删除，但可基于其创建自定义变体
- [ ] 两者均可被流程节点正常引用并真实执行（节点能读到角色定义内容）
- [ ] 角色定义文件真实存在且非空，不是占位内容
- [ ] 每个角色列出多个可复用场景，说明为何不是「某个已有角色换个说法」
