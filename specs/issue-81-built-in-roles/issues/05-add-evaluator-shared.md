# 05 — 新增共享评估角色 evaluator（评估）

**What to build:** 新增通用内置角色 `evaluator`（评估），定位是**可被多种流程共用的基础评估能力**。关键约束：它只定义「如何做一次独立评估」这类长期稳定的能力，**不内置任何具体流程的评价结论枚举**。使用它的流程各自在节点上声明评价契约——例如「优化」流程的三值结论、「探索」流程的三值结论，都由节点提供，角色定义里一个都不能出现。

**Why this one is the tricky one:** 已关闭的 PR #70 里留有一份 `evaluator` 定义，但那是「多视角探索专用的结论评估」，与本 Issue 要求的「共享基础能力」定位相反，**不得原样搬用，需重写**。相比之下 PR #70 的另三个角色（统筹/研究/综合）是被明确评为「高度复用」的。

**与 `review` 的边界**：`review` 面向规范与需求符合性、质量问题审查；`evaluator` 面向给定评价标准下的独立评估结论。两者不合并。

**Blocked by:** 01, 03（需与 `review` 的职责边界对齐后再定稿）

**Status:** ready-for-agent

- [ ] 角色库「内置」分组出现 `evaluator`（中文名：评估）
- [ ] 它可被「优化」流程与「探索」流程同时引用，且两次引用用的是同一个角色
- [ ] 角色定义文件中**不出现**任何具体流程的评价结论枚举
- [ ] 在两种不同节点契约下引用它，各自的三值结论均由节点提供且互不干扰
- [ ] 与 `review` 的职责边界在定义中显式写清，两者不合并
