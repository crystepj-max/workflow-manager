# 06 — 新增专业角色 diagnose（缺陷诊断）

**What to build:** 新增专业内置角色 `diagnose`（缺陷诊断），负责在动手修复之前先把问题定位清楚：还原现象、收集证据、收敛到根因，再交棒给 `dev` 去修。它面向「诊断 · 缺陷修复」流程，但需说明它作为专业能力的独立价值。

**关键约束**：诊断与修复是两件事——诊断错了应回到诊断，修复错了才回到修复。角色定义需把「先有证据再下结论」写成硬规则，避免跳到猜测。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 角色库「内置」分组出现 `diagnose`（中文名：缺陷诊断）
- [ ] 与 `dev` 的职责边界在定义中显式写清：诊断负责定位根因，修复由 `dev` 承担
- [ ] 定义中含「先取证后结论」的硬规则，不允许凭猜测直接给出根因
- [ ] 可基于其创建自定义变体；本身不可编辑、不可删除
- [ ] 角色定义文件真实存在且非空，不是占位内容
