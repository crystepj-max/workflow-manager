# 07 — 新增探索三角色 orchestrator / researcher / synthesizer

**What to build:** 新增三个专业内置角色，共同支撑「探索 · 多视角探索」流程：

- `orchestrator`（探索统筹）：拆解问题、设计专家构成、统筹研究轮次；
- `researcher`（专家研究）：按给定的专家任务书产出一份独立观点；
- `synthesizer`（综合分析）：把多份独立观点综合成共识、分歧与分歧原因。

**关键约束（极易踩坑）**：**不得**为 3–5 个专家分别创建永久角色（Expert A/B/C/D）。专家由 `researcher` 配合运行期动态生成的专家任务书产生，一个 `researcher` 角色，多个运行期实例。

**素材说明**：已关闭的 PR #70 保留了这三个角色的旧定义，维护者评级为「高度复用」，可按正式公共交接与记录契约校准后采用——这与 `evaluator` 的待遇不同（`evaluator` 需重写）。
